# 2026-09-08 更新简讯

- 更新项目依赖和 TypeScript、Jest、Rollup 配置，构建不再依赖 `.secret.json`。
- 以项目内构建插件替代过时的 HTML 和 Screeps 上传插件；上传会校验目标、响应和远端模块内容。
- 修复 Profiler 对方法 `this` 的保持和异常后的调用栈清理，并记录 Framework Memory 映射 TODO。
- 完善 EventBus 类型、作用域存储、取消订阅清理、异常隔离和发布前作用域快照。
- RoomShortcuts 改为模块级全局订阅建筑事件，通过房间名和双 ID 校验增量更新缓存。
- RoomShortcuts 统一空结果契约，加入无视野失效、强制刷新和默认 5000 tick 的缓存校验租约。
- 增加 Runtime、Profiler、EventBus、RoomShortcuts 和构建上传行为测试。
- 统一文档目录结构，根目录仅保留项目入口和代理规范，设计、使用说明及更新简讯集中到 `docs/`。
- 按根目录开发规范重构 `src/` 全部 TypeScript 与 HTML 源文件的注释：补齐文件摘要，并说明关键算法、类型技巧、缓存生命周期、第三方依赖及 Screeps 运行成本；本次未修改任何非注释源码。
- 完善 Leviathan Framework 的生命周期、插件协议、意图仲裁、Memory 拦截、错误隔离、CPU 调度和首版验收设计；框架实例通过 `loop` 方法提供游戏主循环。
- 实现 Framework 首版并接入应用入口：三阶段生命周期、插件依赖排序与边界启停、服务和订阅清理、Memory 迁移回滚与跨 tick 复用、CPU 准入、意图通道及共享锁仲裁。
- 以同步的 trace-mapping 实现错误堆栈还原；加固 Profiler 的观测故障隔离与当前 Memory 访问，将插件执行、错误映射和日志分别计时。
- RoomShortcuts 通过服务插件装配；新增 Framework、Profiler 使用文档及生命周期、存储、异常和真实构建产物的自动化测试。
- 首版验证通过：TypeScript 类型检查、72 项单元测试、4 项构建上传脚本测试、2 项真实打包产物测试及正式构建；另在未复制 `.secret.json` 的隔离目录中确认构建成功。上传测试使用模拟接口，本轮未执行外部部署。
- 完成 Framework Memory 内存化：每个 Framework 实例仅首次挂载时读取并解析 RawMemory，后续 tick 复用常驻 heap 根；迁移改用递归 JSON 克隆，运行中升级也不产生额外 JSON.parse。
