# 2026-09-17

## Core 单一组合根重构

- 发布完整 `CoreRuntime` 契约；Runtime 统一创建并持有 Logger、EventBus、MemoryManager、Profiler、ErrorMapper 与模块上下文工厂。
- Framework 改为强制消费完整 Runtime，移除对同级 Core 工厂的直接依赖与分散的基础能力配置入口；App 只负责创建 Runtime、选择插件并创建 Framework。
- EventBus、MemoryManager、ErrorMapper 与环境适配器改为显式接收 LoggerFactory，删除模块级默认日志工厂，测试在各自装配边界提供依赖。
- ErrorMapper 从 Framework 内部迁为独立 `core/errorMapper` 模块，并补齐对应设计、使用说明与导航。
- 新增 Core 同级依赖静态边界测试，并把该规则写入根开发规范：只有 Runtime 可以导入前序 Core 具体实现，Framework 仅依赖 Runtime 契约。
- 更新真实构建产物测试，使其按正式 API 显式创建 Runtime，并继续验证同步 source map 映射和无存储旁路。
