## Runtime 配置归位

- `RuntimeOptions` 改为按 `platform`、`logging`、`memoryManager`、`profiler`、`errorMapper` 分组，不再平铺具体模块字段。
- `getGame` 归入平台配置；Profiler 开关和存储端口归入 Profiler；source map 加载器与故障报告归入 ErrorMapper。
- 将 Profiler 的统计访问器与标脏回调合并为 `ProfilerStorage`，统一表达统计数据访问依赖。
- 新增独立的 `RuntimeOverrides` 第二参数，测试实例替换不再与生产创建配置混合。

- 审阅时修复 ProfilerStorage 方法脱离对象调用导致的 `this` 丢失，补充统计表替换、报告与清零回归测试。
- 补充 Runtime 配置传递、延迟访问存储、跨 tick 环境查询、实例替换优先级及 Profiler 禁用与暂停采样的区别测试。

验证：`npx tsc --noEmit`、`npm test`（144 项单元测试、4 项构建工具测试、2 项产物测试）、`npm run build` 和 `git diff --check` 全部通过。产物测试包含无密钥环境下的实际构建与连续 tick 执行。
