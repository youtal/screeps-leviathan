## goto 设计审阅调整

- 仅有向房间权重持久化；补齐 createGoto 工厂、插件、移动/hold/flush、权重增删改查及配置诊断接口。
- 矩阵改为 AB 基底、ABC 结构合成缓存和不入库的 creep 临时覆盖，默认禁止进入全部非己方 rampart；采用独立内容版本避免同 tick 更新时间相同。
- 采用 goal/room 下的 4 bit 方向表，不记录起点；补充无环合并与矩阵依赖过期后整 goal 废弃规则。
- 评估两个原生接口后统一采用 PathFinder.search；Room.findPath 保留为便捷脚本及基准对照选择。
- 采用移动尝试双表；当 tick 请求应答，下一 tick 双方同步尝试，之后核验真实位置。
- Framework 的 onTickEnd 在 commit 之后且不可提交意图，因此采用 begin 收集、goto execute 规划、各 owner execute 提交，end 只轮换双表。
- 仅调整设计，未新增或修改运行时代码。
- 核对官方驱动的意图计费去重，明确一次移动约束的收益，避免将同 tick 覆盖 move 简单计为额外 0.2 CPU。
