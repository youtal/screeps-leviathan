# 2026-09-22 更新记录

## MemoryManager 模块审计整改

按 [2026-09-22 模块审计](../audits/2026-09-22-memoryManager.md) 关闭 M1–M8：

- **M1**：`initialize`/`migrate` 的返回值校验后复制为工作对象，返回模块级常量、共用对象或冻结对象不再导致分区间共享或写入异常。
- **M2**：`MemoryManagerOptions` 新增 `getTick`，供缺省平台使用；Runtime 由共享 `getGame` 端口注入 tick 来源，`RuntimeOptions.memoryManager` 不再接受单独的 `getTick`。
- **M3**：受管数据校验拒绝对象与数组上的 Symbol 键。数组元素访问器、数组附加属性与不可枚举属性因成本原因不检出，已写入设计与使用说明。
- **M6**：`Record<number, X>` 可用字符串段访问；`remove` 的可删性区分显式声明键与索引签名，修正字面量 Record 键被误判为不可删的问题。
- **M7**：补充结构错误、调用参数错误、重入与回调内 `remove` 的测试。
- **M8**：更正 `ModuleContext.memory` 注释与 Runtime 使用说明中过时的配置描述。
- **M4、M5**：不修改实现。使用说明新增“提交开销与 CPU 预留”与“共享关系不随持久化保留”，设计 §4.3 同步写明后者。

验证：`npx tsc --noEmit`、`npm test`（Jest 162 项）、`npm run build`、`npm run test:integration`（三个场景）与 `git diff --check` 均通过。未上传游戏服务器。

## MemoryManager 第二轮模块审计整改

按 [模块审计 §6](../audits/2026-09-22-memoryManager.md#6-第二轮审计基线-3cc5c49) 处置 N1、N3–N6，N2 保持待决定：

- **N1**：路径写入的新值在校验的同一次遍历中复制，调用方保留原对象；`initialize`/`migrate` 改用同一机制。
- **N3**：受管校验与 `JSON.stringify` 一致地忽略原型链上的可枚举扩展属性。
- **N4**：装载只解析不编码，同版本申请不再二次解析，片段在首次拼接时生成，迁移前固定基线，旧布局导入的 payload 与保留根字段隔离。reset 首 tick 实测 114 ms → 87 ms。
- **N5**：更正校验成本注释。
- **N6**：新增 `TopKey<M>`，数字索引记录的顶层键重载与路径重载一致。

同步设计 §4.1、§4.3、§5、§9 与使用说明；删除 `visitPublish` 中不再使用的禁止引用检查。验证：`tsc`、`npm test`（Jest 167 项）、`build`、`test:integration`（三个场景）、`git diff --check` 均通过。未上传游戏服务器。
