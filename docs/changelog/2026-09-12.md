## Logger 落地

- 新增 `src/core/logger`：`createLogging` 按装配配置返回 `LoggerFactory`，`scope(name, options)` 派生带前缀的日志器；等级「作用域覆盖 → 装配覆盖 → setting 默认」逐字段用 `??` 回退，关闭等级在格式化前短路。
- `src/contracts/logging.ts` 增补 `LogOutput`、`LoggingOptions`、`ScopeLogOptions`、`LoggerFactory`，把输出端口与作用域派生协议纳入公共契约；`test/contracts.types.ts` 增加日志契约正例与等级键负例。
- 双通道输出：默认 `console.log` 与 `Game.notify(line, notifyInterval)`（分组间隔默认 60 分钟，正整数校验在装配期完成）；邮件策略为装配级 `off | error`，作用域可覆盖，只有 error 等级会发送。端口抛错只丢弃当条日志，日志不依赖 Memory/Profiler/ErrorMapper/Game。
- 日志实现从 `utils/console` 迁出：该目录只保留着色与模板等纯函数（Logger 单向复用 `Color/dyeText`），`src/utils/index.ts`、`console/index.ts`、`setting.ts` 注释同步；`core/*` 不再从 utils 导入日志实现。
- 装配接线：`RuntimeOptions.logging` 与 `FrameworkOptions.logging` 支持注入；`createRuntime` 装配共享工厂并注入模块 env、Profiler 与 EventBus，`createFramework` 同样注入 ErrorMapper、EventBus 与插件 env，未注入时使用 `defaultLoggerFactory` 兜底，保证独立调用与测试可用。
- `createEnvMethods` 的 `notify` 参数改为可选覆盖：`undefined` 跟随装配策略、`false` 强制关闭、`true` 在装配允许时开启；默认行为与之前一致（项目默认不发邮件）。
- 测试：新增 `test/logger.test.ts` 9 个用例（默认等级、作用域覆盖、着色前缀、邮件策略与覆盖、端口抛错隔离、非法间隔、无 Game 环境、默认端口写入与 notify 间隔），`test/console.test.ts` 移除已迁走的等级用例并保留模板回归；`test/contracts.types.ts` 扩充编译期负例。
- 文档：`docs/design/core/logger.md` 与 `docs/usage/core/logger.md` 由占位改为正式设计与使用说明；Runtime、Framework 的设计与使用说明补充日志装配；契约文档、总导航与两级索引同步 Logger 交付状态。
