## Logger 评审修复

- 邮件策略改为**硬上限**：装配级 `notify: 'off'` 时作用域不能用 `notify: true` 打开邮件；装配为 `'error'` 时作用域只能跟随（`undefined`）或关闭（`false`）。契约注释、设计与使用文档同步；新增「装配 off + 作用域 true」用例，该用例在修复前的实现上判失败。
- ErrorMapper 默认报告出口改为在创建映射器时派生一次 `ErrorMapper` 作用域日志器，故障密集时不再逐次创建日志器对象与临时字符串；新增回归用例断言 `scope` 只调用一次、每次故障仍写入。
- 作用域着色前缀改为按等级惰性缓存：每个作用域每个等级只调用一次 `dyeText`，之后每条日志只做一次字符串拼接。
- 内容约定澄清：设计文档不再承诺"日志文本单行"。Logger 不改写内容，普通业务日志约定单行，错误堆栈允许多行并原样保留。
- 「单一组合根」记入 Logger 设计待决事项与 Core 架构 §5：正式 App 只允许一个内核装配入口，Runtime 以完整内核运行时对象交付能力（日志、事件总线、观测、错误映射、存储端口），Framework 消费而不重建；各能力兜底实例仅服务独立测试。该形态随统一内核装配一并交付。
- 契约收尾：`LogOutput` 注释删除“单行”表述，并说明端口文本可能包含换行（错误堆栈），实现不得假设单行。
- 清理：`src/core/logger/.gitkeep` 占位文件随模块落地移除，目录已有真实实现。
- 验证：`npx tsc --noEmit` 通过；`npm test` 通过（9 组、82 个 Jest 用例、4 个构建插件用例、2 个真实 bundle 用例）；`npm run build` 成功；`git diff --check`、改动 TypeScript 文件的 prettier 检查与文档相对链接检查通过。

## MemoryManager 评审修复（未提交）

- **页所有权（阻断）**：新增页内容观察与保留机制——只有"读到过且为空"的页参与分配，目录与迁移 journal 引用的页视为自有，其他工具数据与无归属信封登记为保留页并在 `getStatus().reservedSegments` 暴露；迁移 copy 阶段拒绝写入非空目标页；激活请求改为提交精确页集合（不再并入外部活动页，避免超过单 tick 10 页上限）；未被本 global 申请模块持有的页不再被视为空闲。
- **ready 句柄时效（阻断）**：`access()` 返回的 ready 句柄绑定签发 tick 与数据引用，跨 tick、分区 pending 或数据重载后调用 `query()/commit()` 抛协议错误；契约与使用说明同步该语义。
- **Framework 异常隔离（阻断）**：Memory `begin/end` 移入错误边界并在 `finally` 内层 try/finally 中收尾，任何存储异常都记录为内核故障且一定复位 `running`，不再出现永久"loop is not reentrant"。
- **安静 tick（阻断）**：外部根字段改为写入时现取现序列化 + 键集合/引用变化检测，默认环境下 clean tick 不再每 tick 调用 `RawMemory.set`，片段缓存收益恢复。
- **迁移代际**：新增持久单调 `generationCounter`，每次搬迁取新值，旧页残留信封不会被回读校验误认成本次写入。
- **无模块恢复**：迁移数据改为从存储与已冻结副本搬运，模块本轮未申请也能完成 journal 恢复；中止时清理目标页并保留诊断。
- **窗口完整性**：插件 setup 失败也计入申请可能未收齐；窗口最多延后 `maxStartupDeferrals`（默认 10）个 tick，超限强制封存并在状态中标记。
- **命名空间校验加强**：allocations/rawPartitions/migration 逐项深度校验，半损坏数据直接进入故障状态而不是遍历时崩溃；旧布局导入改为深拷贝，避免模块原地修改污染旧命名空间。
- 测试：新增 11 例回归（外来页保留、未认领信封保留、未申请模块的页保留、ready 句柄跨 tick 失效、带宿主 Memory 的 clean tick 不写、抢占后页复用与代际单调、模块缺席的 journal 恢复、窗口强制封存、精确激活集合、end/begin 抛错不卡死、setup 失败延后窗口），`npm test` 达到 10 组 / 110 项 Jest 用例 + 4 项构建插件 + 2 项 bundle。
- 文档：MemoryManager 设计与使用说明更新页所有权、句柄时效、窗口上限、存储驱动恢复与应用层装配状态；契约与 Framework 设计交付状态同步。
