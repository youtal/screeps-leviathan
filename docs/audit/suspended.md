# 挂起问题列表

本列表记录经评估后无法解决的问题。列入的问题，后续审计不再重复提出；只有当其"重新提出条件"满足时，才重新评估。

## 规则

- **收录条件**：问题无法解决，例如上游没有修复版本，且没有可接受的替代方案。可以解决的问题不进入本列表。
- **挂起类型**：永久挂起，不设定期复查，只在重新提出条件满足时复查。
- **收录方式**：审计者把无法解决的问题标记为永久挂起并写入本列表，在交付说明中告知用户。
- **记录字段**：编号（沿用来源报告中的编号）、日期、来源报告、问题、影响范围、无法解决的原因、重新提出条件。
- **重新提出条件**：写成可核对的事实，例如"上游发布修复版本""该依赖进入构建产物""影响范围扩大到线上运行"。
- **解除**：问题解决或不再存在时，从"挂起中"移到"已解除"，注明日期与原因。
