# 审计报告与里程碑审查

本目录记录两类报告：针对代码、文档或运行情况的审计报告，以及每个里程碑结束时的审查。报告按当时的日期、代码基线与验证范围阅读，不覆盖为当前状态。

## 规则

- 文件命名为 `YYYY-MM-DD-<范围>.md`，开头标明代码基线。
- 审计报告中的每项问题遵守项目 README 的[审计报告](../../README.md#audit-reports)规则：提供可复查的定位与影响依据，区分源码确认、测试复现与待验证推断。
- 里程碑审查记录：已完成的变更、验证结果（包括未通过或未运行的检查）、遗留问题，以及据此调整的设计成熟度标注。
- 整改与复核结果追加在原报告中，与原审计记录分开。
- 无法解决的问题记入[挂起问题列表](./suspended.md)。审计前先读该列表；列入其中的问题不再重复提出，只在其重新提出条件满足时复查。
